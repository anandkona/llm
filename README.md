# React + Vite

This project has been migrated to [Vite](https://vite.dev/) and [React](https://react.dev/).

## Available Scripts

In the project directory, you can run:

### `npm run dev` or `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000) with Hot Module Replacement (HMR).

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Locally previews the production build.
